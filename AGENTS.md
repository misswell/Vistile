# Agent 约定 / Agent conventions

1. 全部使用中文交流。所有面向用户的输出（进度说明、诊断结论、方案、总结、提问）必须是中文。代码、标识符、日志字符串与仓库内文档保持项目原有语言，不做翻译。
   All user-facing output (status updates, findings, plans, summaries, questions) must be in Chinese. Keep code, identifiers, log strings and in-repo docs in their original language; do not translate them.

2. 每条记忆、规则与纠正都同时写入中文和英文。记忆文件正文与 `MEMORY.md` 索引条目应双语呈现，便于在不同语言下都能检索到。
   Record every memory, rule and correction in both Chinese and English. Memory bodies and `MEMORY.md` index entries are bilingual so retrieval works in either language.
